# توقيع m_tayea — Signature Component

ملف التوقيع الرسمي اللي بتركبه في **أي موقع** بتعمله — بيظهر شارة أنبوبية أنيقة في زاوية الشاشة مربوطة بموقعك الرئيسي.

The official signature file for every site you build — shows an elegant pill badge in the screen corner, linked to your main website.

## التركيب | Installation

ضع **سطر واحد** قبل وسم الإغلاق `</body>`:

```html
<script src="https://m-tayea.mtayea.com/signature/mtayea-signature.js"></script>
```

أو لو رافع ملف التوقيع مع الموقع نفسه:

```html
<script src="mtayea-signature.js"></script>
```

خلاص. كده 🎉

## إيه اللي بيحصل لوحده | What It Does

- ✅ يظهر توقيع «صُنع بواسطة **m_tayea**» بشارة زجاجية داكنة بنفس هوية موقعك (وردي نيون)
- ✅ أي حد يضغط على التوقيع بيتنقل لموقعك: `https://m-tayea.mtayea.com`
- ✅ يظهر بحركة ناعمة بعد تحميل الصفحة، وبيخفت على الموبايل
- ✅ مبيشتغلش مرتين لو اتكرر التركيب، ومبيأثرش على سرعة الموقع (أقل من 2KB)
- ✅ بيحترم تفضيل تقليل الحركة (`prefers-reduced-motion`)

## مثال | Demo

افتح `demo.html` في المتصفح وشوف الشكل.

## ملاحظة | Note

التوقيع بيعرض هويتك ويربط بموقعك. **النشر الفعلي** لأي موقع جديد على حسابك بيتم بكوماند واحد (أو ابعتلي وأنا أرفعه وأضيفه لقسم أعمالك على `m-tayea.mtayea.com`).
